Setup

Description

By spending the listed amount of energy, you can set up this weapon on a stable surface or with a bipod. While set up, you ignore the penalty from the weapon's Heavy trait, but you cannot move. This state lasts indefinitely. To end the setup (allowing you to move again), you must spend the same amount of energy, or simply Drop the weapon.

Example

  • Setup (4): Costs 4 energy to set up or pack up. You cannot move while set up.
